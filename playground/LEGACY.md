# LEGACY — pre-pivot universal-contract demo

This playground runs the **pre-pivot `core/` engine** in the browser. It
is a demo of the old `*.contract.json` loop. It is **not** the v1 proof
and must not be treated as recipe-IR evidence.

The v1 **proof** path is `recipe/` plus
[docs/32](../docs/32-recipe-ir-pivot.md) through
[docs/35](../docs/35-two-journey-v1-plan.md). Published `@ds-contracts/*`
still exports the old envelope. Product v1 is incomplete.

This folder was labeled, not moved. No new semver in the commit that
added this file.
