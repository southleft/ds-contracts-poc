# The Channel Table — every CSS computed property, classified once

This table closes the channel vocabulary **top-down**. The bottom-up habit — classify whatever the next design system happens to exercise — is why every new library "finds" an unclassified CSS property. The denominator here is not a library: it is the full `getComputedStyle` enumeration of the capture browser (Chromium 151.0.7922.34, 475 longhands — byte-identical to the `_provenance.channels` list in every committed capture artifact), plus the two synthetic channels the capture itself mints (`translate-x`/`translate-y`) and the contract-channel shorthand spellings the schema carries (background, border-color/-width/-radius/-style, padding-inline/-block, gap, transition, white-space).

Every property is in **exactly one** class:

| class | meaning |
|---|---|
| **CARRIED** | drawn on the canvas — the row names the Figma projection and the engine symbol (`file` + symbol, verified by the gate) |
| **LEDGERED** | carried as data, not drawn — the row names the receipt channel the value rides |
| **REFUSED** | a named wall — conformance case name, FC-* code, or the code-only fallback receipt |
| **INERT** | provably no independent visual effect at computed level — justification in the row |

## How to read a row

- **prior** — where the classification existed before this table (`schema-token`, `schema-declared`, `layout vocabulary`, `conformance`, `capture fold`, `geometry exclusion`, `logical-alias`, `webkit census`), or `none` (decided fresh here — the debt).
- **projection / receipt / code** — the CARRIED Figma projection, the LEDGERED receipt channel, or the REFUSED wall name.
- **value notes** — value-space subtleties: the same property can carry one value shape and refuse another (`border-style: solid` annotates while the stroke draws; `grid-template-columns: 1fr auto` carries, `minmax()` refuses by its G7 name).
- **conformance** — css-dom conformance case ids (`conformance/MANIFEST.json`) that pin the behaviour.

## Custom properties (`--*`)

custom properties are the token SUBSTRATE, not styled channels: var() references resolve through the CSS-vars reader (capture.ts vrefsOf, one indirection hop) into contract token bindings; a custom property observed directly on an element is refused by name as token plumbing (fuse.ts: "CSS custom property, not a styled channel") (anchor: `extract/computed/capture.ts` · `vrefsOf`).

## Planes

Properties are one axis; the capture also models **pseudo-element planes** and **state planes**, and a property row applies on every plane that is read.

- **Pseudo-elements read:** `::before`, `::after`, `::marker`, `::placeholder` (`extract/computed/lib.ts` · `READ_PSEUDOS`).
- **Pseudo-elements named refused:** `::selection`, `::backdrop` (conformance cases pseudo-selection, pseudo-backdrop).
- **Pseudo-elements UNREAD — `FC-PSEUDO-PLANE-UNREAD` (minted by this table):** `::first-line`, `::first-letter`, `::file-selector-button`, `::spelling-error`, `::grammar-error`, `::highlight`, `::target-text`, `::details-content`, `::cue`. these pseudo-element planes are never read by the capture layer and no degradation names them today — a rule styling one is invisible with no receipt. Found-silent.
- **States driven:** default, hover (mouse), active (mouse down), focus-visible (sentinel+Tab keyboard modality), disabled (prop combos), checked (variant axis reclassification).
- **States UNDRIVEN — `FC-STATE-PLANE-UNDRIVEN` (minted by this table):** `:visited`, `:target`, `:focus-within (as a distinct plane)`, `:placeholder-shown`, `:autofill`, `:valid`, `:invalid`, `:user-valid`, `:user-invalid`, `:indeterminate (where no variant axis carries it)`. these interaction/UA state planes are never driven by the capture sweep and nothing names the gap — a library styling one loses the plane with no receipt. Found-silent.

## Found-silent

Classes of loss where, before this table, **no receipt fired anywhere**:

- **pseudo-element planes** (9) — code `FC-PSEUDO-PLANE-UNREAD`: the capture reads only READ_PSEUDOS (::before/::after/::marker/::placeholder); ::selection and ::backdrop are named by conformance cases, but a rule on any plane listed here is dropped with no receipt anywhere in the pipeline.
- **state planes** (10) — code `FC-STATE-PLANE-UNDRIVEN`: the sweep drives default/hover/active/focus-visible (plus disabled and checked through the prop space); a library styling any plane listed here loses the whole plane silently.
- **logical-alias longhands** (38) — code `(none — INERT)`: excluded from fusion by isFusable with no receipt; classified INERT because each is a byte-equal alias of its physical longhand under the pinned writing mode, so no independent fact is lost while writing-mode stays refused by name — the silence is justified, and this row is the written justification.

The two minted FC codes are table-level names for these classes; wiring them into the engine as live receipts is follow-up work, deliberately excluded from the classification-only change that introduced this table.

## The gate

`npm run channel-table:check` (fast lane) refuses when: a property observed by the capture layer (the union of `_provenance.channels` across committed capture artifacts) has no row; a schema channel or conformance channel has no row; a CARRIED row cites an engine file/symbol that does not exist; the JSON is not byte-stable canonical form; or the totals quoted here and in docs/30 drift from the JSON. `--self-test` plants a missing row and a dead symbol and requires both reds.
