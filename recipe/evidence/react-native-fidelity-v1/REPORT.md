## The three numbers

| | what it is |
| --- | --- |
| **historical** | the ink-trim unmasked score exactly as `recipe/fidelity-score.ts` `scoreFidelity` computes it — the number every earlier private run reported |
| **aligned** | the same pixelmatch operating point (threshold 0.1, antialiased pixels excluded) with the two rasters placed by their RECORDED layout origins instead of by ink; integer translation only, refused by name otherwise |
| **glyph-masked** | `scoreFidelity`'s second pass with the native text rects masked on both sides (inflated by the scorer's own 4 px) |

All three are the scorer's antialias-TOLERANT operating point, the one the 5 % bar is defined on. The per-row `exact %` column is the scorer's threshold-0 point on the same ink-trimmed pair (every differing pixel counts, antialiasing included); it is printed so a 0.000 is never read as pixel identity — a one-step colour difference across a whole fill is invisible to the tolerant point and total at the exact one.

## Verdict rule (the existing F1 row policy)

- `pass` — historical ≤ 5 %.
- `named-font-residual` — historical > 5 % AND named in `KNOWN-FAILURES.json` with class `font-substrate` or `font-metrics` AND (glyph-masked ≤ 5 % OR the text rects cover the whole cell) AND aligned ≤ 5 %.
- `named-other` — class `alignment-trim-threshold` only, with the proof recomputed from committed bytes: native interior ≥ the scorer's trim threshold (250) on every channel yet painted, source interior below it, the two within one 8-bit step, aligned ≤ 5 % and glyph-masked ≤ 5 %.
- `fail` — anything else. A `fail` is red; the ratchet only tightens (an unnamed failure is red, a named row that passes is red until removed).

## Text antialiasing: ink mass

Inside the native text boxes (placed by layout origin) Chromium lays down 1.123×–1.359× the ink Figma does for the same glyphs (median 1.143×, 32 rows with text). Ink mass = Σ |pixel − the box's modal background| / 255. It is supplementary and never part of a verdict.

## What this does not measure

- One mount, one initial state per variant, light scheme, one image pixel per CSS pixel. No interaction, hover, focus, responsive or dark-mode state.
- The native side is a dated readback export, not a claim about the live file today.
- Variants listed as not-measured above have no honest like-for-like pair; nothing was substituted for them.
- Appearance only: structure, bindings and editability are qualified elsewhere.
