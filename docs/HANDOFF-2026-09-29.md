## 0. Owner decision (2026-09-29): fix the Figma → React bridge

The owner's words: "We have to fix the Figma-to-React bridge. This is part of
the major thesis of this proof of concept… I want to finish this, and I want
to finish it correctly. We need the bidirectional contract that ensures the
transition from code to canvas and canvas to code."

So:
- **Direction is settled.** Do not propose leading the beta with React → Figma
  alone, and do not narrow the thesis. The contract must carry both ways.
- **Finish line:** first-pass success of at least **80% on never-seen kits, in
  both directions** (the owner's bar from 2026-08-24), measured by the
  real-design-systems scoreboard with every miss named, the same thresholds,
  and no scorer changes.
- **Both directions must be measured.** Today only Figma → React has a
  scoreboard. Build the code-side scoreboard too: React → Figma on real open
  React libraries (shadcn/ui, Radix Themes and others named in docs/GOAL.md),
  created in the owner's live-testing file and read back.
- Interim milestones to report against: M2 = 25% of variants on the 40-set
  test set, M3 = 50%, then the full 204-set sample, then the 80% bar on both
  scoreboards.

**Diagnosis (triage workflow, 15 agents, every verdict challenged):**
the Figma → React importer **drops** facts it cannot express as a token or a
clean per-axis rule, instead of carrying them. Every failing set that packaged
(140/140) has "dropped" notes. Largest causes, by sets affected in the 204:
1. Refusals/crashes on valid input: ~36 sets (property-name collisions 15,
   slot references 5+8, a crash on a null prototype action in
   `extract/figma/rest/map.ts` `mapReactions` (`a.navigation` on `null`) 5,
   TypeScript compile errors in generated code 5, the 30-component limit 3,
   literal "{text}" read as a variable 3).
2. Values that depend on a boolean property or on several axes at once are not
   carried (`core/mint-tokens.ts` ~353 and ~642–692, door
   `mint.nested-triple-refusal`): ~25 sets, about half of all failing image
   comparisons. Example: Radix Themes Button loses its background and height.
3. The REST reader (`extract/figma/rest/map.ts`) drops what the plugin reader
   carries: fixed/absolute sizes (~26 sets), stroke alignment (10), percent line
   height and underline (24), italic.
4. Hidden layers and "show when false" visibility (up to 32).
5. Vector paths and boolean shapes (30–50, large).
6. Icons from other library files ship as empty stubs (~22, large).
7. Font stacks with no fallback (SF Pro renders as Times even on a Mac; 59 sets
   name a single family).
Fonts missing from the check environment move the total only 1–3 points.
`content-size-mismatch` (108 sets) is a true-positive guard, not noise.

## 4. The scoreboard: how to run and read it

- **Kits:** 17 community kits duplicated into the **Southleft** workspace
  drafts (never a client workspace). Keys: `private/beta-kits/kit-files.json`.
  Set inventory (3,200 sets, 60,803 variants; a REST page walk, because
  `/component_sets` returns nothing for unpublished drafts):
  `private/beta-kits/kit-sets.json`.
- **Sample:** 12 sets per kit, first by `sha256(fileKey:setId)`; recorded in
  `private/beta-kits/scoreboard/<kit>.sample.json`. Results per set:
  `private/beta-kits/scoreboard/<kit>/<set>/done.json` (+ `run.log`,
  `result.json`, `dump.json`, `check/receipt.json`, PNGs). Summary:
  `summary.json` / `summary.md`.
- **Fixed hill-climb test set:** `private/beta-kits/hill-climb-set.json`
  (40 sets, 879 variants: 2 packaged public sets per kit + the 6 passes).
  Measure every fix on it before and after.
- **Tools** (`private/beta-kits/tools/`): `run-scoreboard.mjs` (copy it into
  the checkout you want to measure and run it there; it runs
  `npm run figma:to-react -- --url … --out …` per set; `--per-kit`,
  `--concurrency 1`, `--gap-seconds 15`, `--only <kit>`; resumable; reruns a
  set once after a rate limit), `summarize.mjs`, `kit-inventory.mjs`,
  `kit-scoreboard.html` (the published page), `shift-lowering.mjs`
  (see §6).
- **Pacing:** Figma's REST budget is per token. One check at a time, 15 s
  apart. Two at once produced 429s that were first misreported as failures.
- **Verdicts:** pass = every variant within 5% image difference on white AND
  black, every Figma text and icon present, size within 2 px (and, after lane
  A part 2, text color and font match). Unverified = could not be measured
  (never a pass). Refused = named stop before packaging. **Never loosen these
  thresholds.**

**Engineering traps:**
- **Engine receipt:** any change to core code bundled into the plugin requires
  `node scripts/build-plugin-zip.mjs --update-engine-receipt` and committing
  `figma-sync/plugin/engine.receipt.json`. The fast lane does not catch a stale
  receipt; the app refuses to start with one. Two PRs that both re-record it
  conflict: take main's, rebuild (`npm run prep:core`), re-record.
- **Lowering citations:** `spec/lowering.json` cites exact lines in
  `core/emit-figma-script.ts`. After edits run
  `npx tsx scripts/lowering-lines.ts --write`. If it refuses with
  `lowering-rule-site-not-unique`, map lines through the diff with
  `node private/beta-kits/tools/shift-lowering.mjs <base-ref>` (starting from
  the base's `spec/lowering.json`), then run the official tool again.
- **Cold tree:** build `packages/schema`, `core`, `cli`,
  `emitter-web-components` (in that order) before gates; `npm run prep:core`
  after every branch switch.
- **D.175 seed:** an empty root-content slot is written 0.01 px wide (Figma
  stores 0.009999999776482582). Readers must use `emptySlotWidth` /
  `ROOT_CONTENT_EMPTY_WIDTH_SEED` (`core/native-float32.ts`), never `=== 0`.
  React → native benchmark cells only replay plan hashes, so a writer change can
  break live readback with every gate green; only a live run catches that.
- **Fresh clone finds first-run bugs** the owner's checkouts cannot (their
  `private/` is full). Recipe:
  `git clone --shared --no-checkout /Users/tjpitre/Sites/ds-contracts-poc <dir>`,

- **`npm run parity`** exits 1 on a healthy tree (snapshot expiry); see

- **Figma plugin by computer use:** background input cannot launch a plugin.
