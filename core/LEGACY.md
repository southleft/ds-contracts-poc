(`propose-figma` → `*.contract.json` → emit). It still runs. It is
CI-load-bearing. It is **not** the v1 proof.

[docs/32](../docs/32-recipe-ir-pivot.md) through
[docs/35](../docs/35-two-journey-v1-plan.md). The playground is a demo of
this older loop, not that proof. Published `@ds-contracts/*` still
exports this envelope. Product v1 is incomplete.

added this file.
