## Why astryx cannot run MUI's pass

MUI ships Emotion runtime styles whose emitted rules NAME the token each
channel binds (`var(--mui-palette-primary-main)`), so `promote-floor.mjs` aliases
on RECORDED EVIDENCE. StyleX compiles the token name away — the atomic class
carries a literal hex — so astryx has **no `source-bindings.json` by
construction**. All that survives is the VALUE, so this example runs a value
join that RANKS and PRESENTS and never auto-resolves.

A color channel on a zero-width border paints nothing. card's `default` variant, whose border IS 1px, is deliberately NOT here — it is #ccd3db and sits in the review queue.
