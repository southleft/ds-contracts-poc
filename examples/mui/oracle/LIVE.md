# MUI oracle — live Figma session playbook

Human-started session for `corpus.liveSessionMinimum`: **button**, **switch**,
**table**. Proves the offline oracle (`npm run mui:oracle:offline`) against a
real canvas: emit/apply → dump read-back → controlled edit → detect drift →
restore → compare.

Do **not** seed TextField or SpeedDial in this session. Do **not** weaken
`accuracy/baseline.json` / grammar counts. Agents must not perform live Figma
writes for the operator — you run Figma; the repo only records receipts.

Sibling offline docs: [EXPECTED.md](./EXPECTED.md), [corpus.json](./corpus.json).
Receipt scaffold: [live/README.md](./live/README.md).

---

## Prerequisites (repo, offline)

Run these on the commit you will paste from. All are local / headless.

```bash
# Frozen corpus + disposition sidecars
npm run mui:oracle:corpus:check

# Offline oracle (28 MATCH · 4 PENDING · 0 FAIL at Wave 2 land)
npm run mui:oracle:offline
# → examples/mui/oracle/REPORT.md + report.json

# Per-component emit referee + headless execute
node examples/mui/scripts/figma-compile-receipt.mjs
# → examples/mui/receipts/figma/COMPILE-RECEIPT.md

# Optional fidelity ladder / drift instruments (no live write)
npm run canvas:binding:check
npm run variant-drift:check
npm run extract:figma:mcp:receipt   # replays extract/figma/mcp/fixtures/ → RECEIPT.md
```

Artifacts you will paste or re-apply from:

| Artifact | Path |
|---|---|
| One-paste bundle (recommended) | `examples/mui/figma/mui.bundle.json` |
| One-paste compiled batch | `examples/mui/figma/GENESIS-BATCH.figma.js` |
| Per-set scripts | `examples/mui/figma/button.figma.js`, `switch.figma.js`, `table.figma.js` (+ `00-tokens.figma.js` first if not using bundle/batch) |
| Genesis how-to | `examples/mui/figma/GENESIS.md` |
| Compile receipt | `examples/mui/receipts/figma/COMPILE-RECEIPT.md` |
| Anatomy dump engine | `extract/figma/dump.plugin.js` (dump v1.13) |
| MCP import / receipt pattern | `extract/figma/mcp/` (`README.md`, `receipt.ts`, `RECEIPT.md`, `fixtures/*.mcp.json`) |

## Session scope

| Stem | Contract | Why in minimum |
|---|---|---|
| `button` | `mui.button` | Large cartesian + disabled / state preview |
| `switch` | `mui.switch` | `checked` as VARIANT axis |
| `table` | `mui.table` | Supported organism; inlined checkbox; stickyHeader refused by name |

Record one receipt directory per stem under `examples/mui/oracle/live/<stem>/`.

---

## Step 0 — Open a clean file

1. Open a **blank** Figma file (or a dedicated scratch file for this run).
2. Note `fileKey` from the URL (`figma.com/design/:fileKey/...`). Redact in
   the receipt if needed (`REDACTED` or last 4 chars only).
3. Install / open the DS Contracts plugin for this repo build.

---

## Step 1 — Emit / apply (or paste genesis / bundle)

**Preferred — one JSON paste**

1. Plugin → **Build** / **Generate** tab (see `examples/mui/figma/GENESIS.md`).
2. Paste entire `examples/mui/figma/mui.bundle.json` → Generate.
3. Confirm pages/sections for Button, Switch, Table (and the rest of the pilot
   kit — that is expected; only the three stems need live receipts).

**Alternate — one compiled script paste**

1. Plugin → **Paste a script**.
2. Paste entire `examples/mui/figma/GENESIS-BATCH.figma.js` → Run.

**Debug — single component**

1. Paste `00-tokens.figma.js`, then `button.figma.js` / `switch.figma.js` /
   `table.figma.js` as needed.

Headless equivalence of bundle vs batch is already gated by
`scripts/plugin-engine-check.mjs` (foreign-token-bundle / mui-figma-genesis).
Live session proves the **desktop** path, not that gate.

Mark receipt step: `emit-apply`.

---

## Step 2 — Dump read-back

Canonical capture: Plugin API dump (native variable names).

1. Select the component set (or page section) for the stem under test.
2. Run `extract/figma/dump.plugin.js` in a Plugin API console / runner bridge
   that can execute in the open file (same boundary as
   `parity/extract-figma.plugin.js`).
3. Save the returned JSON, e.g.
   `examples/mui/oracle/live/<stem>/dump.readback.json`
   (gitignored locally is fine; receipt only needs the path + dump version).
4. Propose offline from the dump:

```bash
npm run extract:figma -- examples/mui/oracle/live/<stem>/dump.readback.json
```

**Optional third rung (names without Enterprise variables API):** with the file
open as the desktop **active tab** and Dev Mode MCP on
(`http://127.0.0.1:3845/mcp`):

```bash
npm run extract:figma:mcp -- '<figma-node-url>' \
  --out examples/mui/oracle/live/<stem>/mcp \
  --target Button   # or Switch / Table
# optional: --fixture … to record like extract/figma/mcp/fixtures/*.mcp.json
```

Receipt pattern to mirror: `extract/figma/mcp/RECEIPT.md` (generated by
`npm run extract:figma:mcp:receipt` from `extract/figma/mcp/receipt.ts`).

Mark receipt step: `dump-readback`. Record set / variant node ids if useful.

---

## Step 3 — Controlled edit

Inside **one** variant of the stem under test, make a **small, reversible**
edit that changes a bound fact — same spirit as
`parity/receipts/live-figma-variant-drift.md`:

- Prefer a padding / fill / radius literal change that **detaches** a variable
  binding, or a visible layout delta on a named part.
- Do **not** rename the set, delete variants, or edit unrelated components.

Record before-stamp / edit description / after-stamp (fingerprint or dump
diff). Mark receipt step: `controlled-edit`.

---

## Step 4 — Detect drift

Re-dump or recompute fingerprint after the edit. Drift must be **visible by
name** (part path + field / binding), not silent.

Offline instruments that document the expected detection vocabulary:

```bash
npm run variant-drift:check
npm run canvas:binding:check
```

Live evidence: dump delta or v6 fingerprint lines (see live Tooltip receipt
under `parity/receipts/live-figma-variant-drift.md`).

Mark receipt step: `detect-drift`.

---

## Step 5 — Restore

1. Restore the edited value **and** re-bind the original variable (slash-form
   name from the dump).
2. Re-dump / recompute — must match the Step 2 baseline (zero residual delta
   on the controlled facts).
3. Confirm the set still matches compile-receipt expectations for that stem
   (variant count / axes in `COMPILE-RECEIPT.md`).

Mark receipt step: `restore`.

---

## Step 6 — Compare to offline oracle

1. Re-run offline oracle on the same commit:

```bash
npm run mui:oracle:offline
```

2. For each stem, fill `live/<stem>/receipt.json` + `RECEIPT.md`:
   - `offlineVsLive.agreement`: `true` only when live canvas facts agree with
     the offline disposition / report for that stem (PENDING dump-dependent
     channels stay PENDING — do not invent green).
   - Quote offline counts from `examples/mui/oracle/report.json` / `REPORT.md`.
3. Validate receipts:

```bash
npm run mui:oracle:live:check
```

Mark receipt step: `compare-offline`.

---

## Live-only defects (hard gate)

If the live canvas disagrees with offline **or** exposes a bug only visible
in Figma desktop:

1. Set `offlineVsLive.agreement` to `false` (or leave unset until closed).
2. Add an entry under `liveOnlyDefects[]` with a stable `id` + `summary`.
3. **Required before any fix is accepted:** `headlessReproduction` — a path or
   command that fails offline without Figma desktop (fixture under
   `extract/figma/`, mock execute in `scripts/plugin-engine-mock-figma.mjs`,
   eval, or a new `*.dump.json` + `npm run extract:figma -- …` assertion).

`npm run mui:oracle:live:check` **fails** if a receipt claims
`offlineVsLive.agreement: true` while listing a live-only defect that lacks
`headlessReproduction`.

---

## Checklist (per stem)

Copy into `live/<stem>/RECEIPT.md` and tick:

- [ ] Prerequisites green (`mui:oracle:offline`, compile receipt)
- [ ] `emit-apply` — bundle or GENESIS-BATCH (or tokens + stem script)
- [ ] `dump-readback` — `dump.plugin.js` JSON saved; optional MCP rung
- [ ] `controlled-edit` — one reversible bound-fact edit
- [ ] `detect-drift` — named delta observed
- [ ] `restore` — baseline restored + rebound
- [ ] `compare-offline` — receipt filled; `mui:oracle:live:check` green
- [ ] No TextField / SpeedDial seeding; accuracy baselines untouched

---

## Out of scope

- Seeding `text-field` or promoting `speed-dial`
- Shrinking accuracy denominators or grammar refusal ratchets
- Treating MCP / REST name joins as stronger than the plugin dump bar
- Agent-driven live Figma writes in CI
