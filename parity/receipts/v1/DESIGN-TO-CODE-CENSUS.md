## The bar

A deterministic way of creating something from design to code."* Pass condition: every Figma-side fact on every set is CARRIED into the contract (and on into the generated code) or NAMED by a receipt — **SILENT = 0** — and the whole pipeline is byte-deterministic.

## The designer's CLI sequence (what these numbers measure)

```
# 1. dump the canvas over REST (read-only; FIGMA_TOKEN)
npm run extract:figma:rest -- https://www.figma.com/design/<fileKey> --out dump.json
# 2. propose contracts from the dump (exact mode for a stamped kit;
#    add --reviewable-inversion for a foreign kit, with ITS tokens)
npm run extract:figma -- dump.json --out proposed --tokens <kit dtcg files>
# 3. generate the code — React + stories, then Web Components
npx ds-contracts generate proposed/*.contract.proposed.json --out src \
  --stories --tokens <kit dtcg files>,proposed/minted.dtcg.json
npx ds-contracts generate proposed/*.contract.proposed.json --out wc \
  --target web-components --emitter @ds-contracts/emitter-web-components \
  --tokens <kit dtcg files>,proposed/minted.dtcg.json
```

The gate re-runs exactly this pipeline in memory from the committed fixtures (`extract/figma/fixtures/census-d2c/`, capture provenance in `<kit>.capture.json`) — no network, no hands.
